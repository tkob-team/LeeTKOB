# Count distinct values

Read `n` integers and print how many different values they contain. This lab practises
writing the comparison logic yourself instead of letting a library deduplicate for you.

## Input
- Line 1: `n` (1 ≤ n ≤ 1000).
- Line 2: `n` integers `a_i` (|a_i| ≤ 10^9).

## Output
- One line: the number of distinct values.

## Example
Input
```
6
3 1 3 2 1 3
```
Output
```
3
```

## Limits
Time limit: 2 seconds. Memory limit: 256 MB. Compiled with `g++ -std=c++17 -O2`.
