# Digit sum without loops

Read a non-negative integer written with up to 1000 digits and print the sum of its digits.
This lab practises recursion: the program must not contain any loop.

## Input
- One line: the number, 1 to 1000 decimal digits, no sign, no leading spaces.

## Output
- One line: the sum of the digits.

## Example
Input
```
90817
```
Output
```
25
```

## Limits
Time limit: 2 seconds. Memory limit: 256 MB. Compiled with `g++ -std=c++17 -O2`.
